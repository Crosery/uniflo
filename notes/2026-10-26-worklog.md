1. **FTS 显式内容遇到暂态锁后丢失**：`env CARGO_TARGET_DIR=/Users/crosery/work_file/Uniflo/target cargo run --offline --manifest-path /tmp/uniflo-lock-probe.xWyUHR/Cargo.toml` → exit 101。`second_writer_accepted=true`；`errors=1`；`last_error=Some("write: database is locked: Error code 5: The database file is locked")`；释放锁后 `recovered_hits=0`，应为 1。`fts.rs` 的 rolling transaction 使用 `BEGIN`；`commands()` 在执行前取空队列，失败后未恢复显式请求。
2. **WAL 旧快照无法升级写事务**：同一探针 `-- snapshot` → exit 101，`Error code 517: Cannot promote read transaction to write transaction because of writes by another connection`。这是延迟事务读后遇到另一个连接提交的确定性回路。

5. **macOS 别名监听漏掉另一个配置根**：`target/debug/watch_alias` 编译引用仓库实际私有 `watch.rs`，运行真实 FSEvents，在临时目录写合成文件 → exit 101，`logical_root_notified=true canonical_root_notified=false`。父 symlink 和 canonical 子目录同时配置时，只映射第一个前缀会漏通知另一个根；应通知所有匹配配置根而非只选最长前缀。
