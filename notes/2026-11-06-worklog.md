## 会话对话历史自动向上分页

用户要求：会话详情不要每页点击「加载更早」，向上滑动时实时加载，并提供直接到最顶的操作。

实现：

- `examples/web/index.html`：`#timeline` 在滚动到顶部前 320px 自动请求 `before=next_before`；分页前后按 `scrollHeight` 差值修正 `scrollTop`，保持当前可见内容不跳动。
- `#more` 改为「到最顶」按钮：点击后顺序加载剩余历史并在完成后滚到 `scrollTop=0`；自动加载期间按钮显示「正在加载更早…」，无更多时显示「已到最顶」，失败时允许继续上滑重试。
- `crates/uniflo-gateway/src/index.html` 同步内嵌副本；`cmp` 确认两份页面一致。
- `scripts/demo-e2e.mjs` 增加 SSE / WebSocket / NDJSON 三种传输的自动上滑加载、滚动位置保持和「到最顶」断言。
- `docs/console.md` 补充对话分页行为说明。

验证：

- `cargo build --release -q`：通过。
- `cargo test -p uniflo-gateway -q`：31 passed（8 suites，14.40s）。
- `node --check scripts/demo-e2e.mjs`：通过。
- `UNIFLO_BIN=target/release/uniflo bun scripts/demo-e2e.mjs`：通过，`{"ok":true,"passed":191,"failed":0}`。SSE 151→251、WebSocket 150→256、NDJSON 150→261；三种传输均验证自动上滑加载、保持非零滚动锚点，以及「到最顶」后 `top=0`。

## 0.2.7 历史分页与直接到顶修复

- 用户反馈「加载失败，继续上滑重试」，且「到最顶」没有直接到达会话开头。合成夹具把工具调用放在上一页、工具结果放在当前页首：0.2.7 页面复现该提示。原因是配对时 `drop()` 移除了当前页首的工具结果，而插入锚点仍指向被移除的节点，`insertBefore()` 抛错；不是这次合成复现中的 HTTP 失败。
- 改用独立的临时注释节点作为分页插入锚点。请求短暂失败时最多自动重试两次；持续的真实 HTTP / 网络错误仍显示实际原因，不能承诺断网或源文件不可读时一定成功。
- 「到最顶」入口固定在对话滚动区顶部，避免自动分页后随旧页被推到屏幕外。点击后一次 `oldest=true` 请求读取并显示最早一页，提供「跳到最新」返回；不再循环 `before` 分页。`Engine::oldest` 使用 `Adapter::read_all` 顺序读取会话，按位置保留最早一页及其后续覆盖；JSONL 按块读取，归档沿用归档解码。
- 修前 `E2E_ONLY=runHistoryBoundary UNIFLO_BIN=target/release/uniflo bun scripts/demo-e2e.mjs`：边界用例失败，页首为 `tool_result`、未配对，显示「加载失败，继续上滑重试」。修后 `E2E_ONLY=runHistoryBoundary,runHistoryTop UNIFLO_BIN=target/debug/uniflo bun scripts/demo-e2e.mjs`：6 passed、0 failed；包含页首结果配对、一次网络中断自动恢复、1500 事件会话上真实鼠标点击可见按钮后一次请求到首事件，以及返回最新。
- `cargo test -p uniflo-gateway --test gateway rest_endpoints_shapes_and_paging -- --nocapture`：1 passed；`cargo test -p uniflo-gateway --test cleanup -- --nocapture`：5 passed，覆盖普通和归档会话最早页。
- `UNIFLO_BIN=target/debug/uniflo bun scripts/demo-e2e.mjs`：196 passed、0 failed，三种传输均验证一次请求到首事件；浏览器在隔离合成会话中实点按钮，观察到首事件与 `scrollTop=0`。
