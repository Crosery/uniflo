# 2026-10-04 worklog

> 封存 v0.1.0 稳定版，落地 geek_main 分支模型规范（stage 预发布集成），支持 prime-agent、cline 系列（cline, roo, kodu）及 kilo 进程追踪。

状态：`historical` · 更新：2026-10-04

## 做了什么

1. **版本封存与分支规范落地**：
   - 封存当前稳定版，在 `main` 打发布 tag `v0.1.0` 并推送到 GitHub 远端。
   - 参考 `/Users/crosery/work_file/geek_main/docs/conventions/BRANCHING.md` 落地双长期分支模型：`main`（正式稳定）+ `stage`（动态预发布集成分支）。
   - 从 `main` 拉出 `stage` 分支并推送到远端。
   - 新增 `scripts/check-branch-invariants.mjs`，硬性检验两条不变量（I1: `stage >= main`；I2: `main` 不得领先 `stage`）与分支命名卫生规则（只用 `/` 分层，不用 `-`，词间用 `_`）。
   - 编写 `docs/conventions/BRANCHING.md`，同步更新 `docs/conventions/GIT.md`、`docs/README.md`、`AGENTS.md`。
   - `scripts/verify.sh` 与 `.github/workflows/ci.yml` 引入分支不变量门禁（CI 增加 `fetch-depth: 0` 保证两分支历史完整性）。

2. **新增 prime-agent 支持**：
   - 调研并实测本机 `~/.prime/agent/sessions/`：共 36 个真实会话文件，基于 Pi/RLM 协议架构。
   - `crates/uniflo-adapters/src/pi.rs` 扩展直接根目录（flat root）扫描与 cwd 匹配，新增 `prime()` 构造器，并接入 `prime-agent` 进程探测（`is_prime`）。
   - `decode` 补全对 `child_usage_attributed`（转换为 `Usage`）与 `agent_status`（转换为 `System`）的解析，将 `session_state`、`git_state` 纳入忽略列表。
   - 新增 `crates/uniflo-adapters/src/prime.rs` 模块与 `prime` cargo feature（依赖 `pi`）。
   - 单元测试新增 `prime_flat_directory_and_attributed_usage`。

3. **新增 cline 及相关系列（Roo Code, Kodu）支持**：
   - 新增 `crates/uniflo-adapters/src/cline.rs` 及 `cline` cargo feature，支持：
     - `cline`：Cline（`saoudrizwan.claude-dev`），覆盖 VS Code / Cursor / Windsurf / VSCodium 等应用根目录。
     - `roo`：Roo Code（`rooveterinaryinc.roo-cline`）。
     - `kodu`：Kodu（`kodu-ai.kodu`）。
   - 针对 `ui_messages.json` 完整 JSON 结构做 `read_whole` 解析：
     - `say: "task"` / `user_feedback` → `Body::UserMessage`，提取标题与开始时间。
     - `say: "text"` → `Body::AssistantMessage`。
     - `say: "reasoning"` → `Body::Reasoning`。
     - `ask: "tool"` / `say: "tool"` → 结构化解析 `Body::ToolCall` / `Body::ToolResult` 并按 `call_id` 配对。
     - `say: "command"` / `command_output` → 转换为 `execute_command` 工具调用与输出。
     - `api_req_started` / `api_req_finished` → 解析 `tokensIn`/`tokensOut`/`cacheReads` 为 `Body::Usage` 并提取模型信息。
     - `completion_result` / `ask: "followup"` → `Body::TurnEnd`。
   - 单元测试新增 `cline_task_roundtrip`，断言完整用户提问、工具调用、执行、用量、结束状态。

4. **完善 kilo 及 OpenCode 系列进程映射**：
   - 在 `crates/uniflo-adapters/src/opencode.rs` 中为 `OpenCode` 适配器（包含 `opencode`、`kilo`、`zcode`、`mimocode`）实现 `live(&self)` 接口。
   - 依据命令行进程参数（`kilo`、`kilocode`、`opencode`、`mimocode`、`zcode`）配合进程工作目录，查询 SQLite 会话表中 `directory` 匹配的最新活跃会话，建立实时 `LiveSession` 进程映射。
   - 在 `crates/uniflo-adapters/Cargo.toml` 中显式暴露 `kilo` feature（作为 `opencode` 的 feature alias）。
