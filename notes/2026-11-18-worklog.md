# 2026-11-18 · Worklog

## Antigravity（`agy`）适配完善：用量定价、链路挂接、存活映射与 `setup` / `memory` 接入

分支 `stage`（基线 `c0a0eb9`）。工作区原有 `.gitignore`、`crates/uniflo-search/src/fts.rs`、`crates/uniflo-search/tests/fts.rs` 的未提交改动保持不动，不纳入本次提交。

### 根因

1. **会话用量与模型缺失**：`crates/uniflo-adapters/src/antigravity.rs` 此前未解析 `transcript.jsonl` 中非 `RUNNING` 的 `PLANNER_RESPONSE` / `CHECKPOINT` token 与 `model` 字段，也未读取 `conversations/<id>.db` 的 `steps.metadata`（`ModelUsageStats` 的 `thinking_output_tokens` / `cache_write_tokens`、旧版会话无内联 `model` 时的枚举与 `model_info` 映射）；实时追尾时还存在 `transcript.jsonl` 先写入 `DONE`、`conversations/<id>.db-wal` 稍后落盘 `steps.metadata` 的时序差。此外，旧缓存 `usage-v1.json`（`LEDGER_VERSION = 1`）已为既有 Antigravity 会话存下空账本，升级后不会自动重算。
2. **推理强度 `-medium` 模型未命中定价**：`crates/uniflo-core/src/pricing/catalog.rs` 为保护 `mistral-medium` 将 `medium` 列入 `TIER_WORDS`，`name_windows()` 全局禁止剥离 `medium`，`Catalog::similar()` 也仅对 Claude 放行 `medium` / `max`，导致 `gemini-4-{carbon,argon,hydrogen}-medium`、`gemini-3.{6,7,8}-flash-medium`、`gpt-oss-120b-medium`、`gpt-5-medium` 等带推理强度后缀的模型无法回退到基础模型而变成 `unpriced`。
3. **Swarm 子代理状态、链路与标题**：
   - Swarm worker 通过调用 `swarm_wait` 挂起等待唤醒（工具结果 `DONE` 后无后续 `PLANNER_RESPONSE`），旧适配器未发出 `turn_end`，导致睡眠中的 worker 一直显示为 `work`；`PLANNER_RESPONSE` 为 `CANCELED` / `CANCELLED` 时也缺少 `turn_end`。
   - `crates/uniflo-core/src/trajectory.rs` 的 `spawns_agents` 只匹配含 `agent`、`task`、`spawn` 的工具名，未识别 `swarm`，导致 Antigravity swarm 子会话未挂接到发起它的工具调用上。
   - 子代理在 `conversation_summaries.db` 中常只有 `agent_name` 而 `title` 为空，且 CLI 会话摘要有时镜像在另一根目录（`~/.gemini/antigravity/conversation_summaries.db`），缺少低优先级 `agent_name` 回退与跨根目录回退。
4. **工作区 URI、用户输入提取与存活句柄映射**：
   - `trajectory_metadata_blob` 中 `file://` URI 长度达到或超过 128 字节时单字节长度假设失效，且 `uri_to_path` 未做 `%XX` UTF-8 百分号解码（含空格或中文目录无法还原为真实路径）。
   - `clean_user_input` 只检查前缀 `<USER_REQUEST>`，遇到前置块（如 `<GRILL_ME>...</GRILL_ME>`）时未能提取其中的 `<USER_REQUEST>`。
   - `is_antigravity` 未跳过带独立值参数（如 `--model x`）的值 token，也未排除子命令 `acp`；进程打开文件映射未覆盖 `conversations/<id>.db-shm` 与 `presence/<id>.lock`。
5. **`setup`、`memory` 与 `resume` 接入缺失**：
   - `uniflo setup` 尚未登记 `antigravity`（`agy` 别名、`~/.gemini/config/mcp_config.json` 与 `~/.gemini/config/skills/uniflo`）。
   - `uniflo-core::memory` 未收录 Antigravity 全局规则 `~/.gemini/config/GEMINI.md` 与项目规则 `.agents/rules/*.md`。
   - `uniflo resume` 在切入已存在的会话工作目录时未同步环境变量 `PWD`。
