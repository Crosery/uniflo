# web-console 规格

网页演示（`examples/web/index.html`，网关在 `/demo` 提供，副本位于 `crates/uniflo-gateway/src/index.html`）是 Uniflo 对外接口的参考客户端。本次重做后，它覆盖会话、用量与费用、全文检索、会话管理和活跃度洞察，并加入 harness 图标和回合结束通知。

设计上吸收 Wake 和 console 的优点：
- 品牌图标作为每行的引导；
- 过滤状态全部写进 URL；
- 未定价的项目明确显示出来；
- 失败时保留上次的数据并注明原因。

同时规避 Wake 的痛点：
- 字号过小（支持缩放、正文不小于 13px）；
- 用单色阶梯来区分系列（改用品牌色或分类色）；
- 没有实时状态（保留并强化 live 状态）。

继续保持单文件、免构建、可离线，以及既有的响应式断点与键盘操作。

## harness 图标

- 页面为每个 harness 内联一份单色 SVG，用 CSS `currentColor` 或 mask 按主题着色。来源优先 lobe-icons（MIT）；lobe-icons 没有的，用该 harness 或其厂商官方仓库、官网发布的标识（如 pi、oh-my-pi、Factory、Craft、DeepSeek），统一处理成单色，来源与许可写进 `THIRD_PARTY_NOTICES.md`。只有确实找不到任何官方标识的 harness 才显示两个字母组成的字母块，并在文档中列出。
- 网关提供 `GET /v1/harnesses/{id}/icon.svg`，`Harness` 新增可选字段 `icon`，值为该接口的路径，供外部客户端使用。
- `THIRD_PARTY_NOTICES.md` 写明 lobe-icons 的许可证和"商标归各自所有者"的声明。

## 视图与导航

- 顶部导航包含五个视图：会话、用量、检索、管理、洞察。
- 当前视图和各视图的过滤条件都写进 URL（hash 或 query），刷新或分享链接后能恢复同一状态。
- 会话列表与会话详情沿用既有能力，并新增以下内容：
  - 侧栏顶部是搜索框，下面一行是 harness 选择框和「筛选」按钮。不显示「会话」标题和条数/耗时，harness 选择框本身不带计数。
  - 「筛选」菜单列出 工作中、进程在运行、隐藏子代理、最近 24 小时、已归档，每项附一句说明；勾选即写入查询，按钮上显示已启用的个数。
  - 分组标题（工作中、今天、昨天…）不带计数。
  - 每行显示品牌图标、标题、目录、时间和费用；不显示模型和 pid。费用低于 $0.01 或未定价时不显示。
  - 归档会话带徽标；
  - 有子代理的父会话，行内费用显示「本会话 + 全部后代子代理」的合计（`Session.family.cost_usd`），悬停显示「本会话 $x + N 个子代理 $y」；子代理行显示自身费用；子代理用量变化时父会话合计随推送更新；
  - "恢复"按钮：复制命令，在 macOS 上还可以选择终端直接打开；
  - "清理"入口。

## 会话详情

参照 DeepSeek Harness 会话视图的「对话 / 轨迹」tab。会话头下方是一排视图 tab，原「每步用量」下拉表和右侧详情栏及其切换按钮不再存在。会话头的元信息里只显示合计金额，拆分放在悬停提示里。会话内不足 1 美分的金额显示 4 位小数。

- **tab**：对话、链路、用量、子代理（带个数，没有子代理时不显示）、信息。只有子代理带数字。
  - 当前 tab 写进 URL 参数 `tab`，默认是对话，刷新或分享后恢复。
  - 切换会话时保持当前 tab。
- **对话**：沿用现有的事件流渲染、翻页、跳转与「工作中」提示。精简三处：
  - 回合页脚只写用时和结束时间，非正常结束时写中文原因（已中断、出错、已取消、输出达上限、已拒绝）；
  - 用户消息的时间悬停才显示；
  - 思考折叠条不显示字数。
- **链路**：数据来自 `GET /v1/sessions/{key}/trajectory`。
  - **工具栏**：展开/收起全部轮次、「实际时长 / 等宽」切换、搜索链路（按名称、参数摘要、回复预览过滤行）。不显示汇总。
  - **时间概览**：按真实时间画出模型、工具、子代理三条泳道和轮次分界，选中轮次时高亮其时间范围；「等宽」时每条记录等宽排列。
  - **表格**：按「轮 → 步 → 记录」分层，列为 时长、Token、费用。Token 是输入、缓存读取、缓存写入、输出之和，分项放在悬停提示里。窄时先去掉 Token，再去掉时长。
    - 轮次行：用户输入预览，费用含本轮启动的子代理。
    - 步骤行：模型与会话模型不同时标出模型。
    - 记录行：思考、回复（预览）、工具调用（名称、参数摘要、耗时、成功/失败/运行中）、子代理（标题、失败标记；可原地展开它自己的链路）。行内不显示步数、工具数、字数。
  - **记录详情**：选中一行后在表格右侧打开，j/k 上下切换，Esc 关闭。内容一屏滚动，没有内层 tab。
    - 模型步骤：
      - 费用：逐类列出 token × 单价 = 金额，合计等于该步费用；harness 自报或未定价时注明原因；
      - 上下文占用；
      - 时间线：请求开始、模型生成、各工具、下一步开始；
      - 「在对话中定位」。
      不显示会话累计、吞吐和事件 id。
    - 工具调用：参数和结果。
    - 子代理：费用与各类 token，打开会话或原地展开。
- **用量**：
  - 合计（本会话 + 全部子代理）及两者的拆分条和金额；
  - 最后一步的上下文占用；
  - 每步费用柱图：子代理费用叠加在启动它的那一步，按轮次分组，点击柱子跳到链路中对应步骤；
  - 用到不止一个模型时显示按模型表：模型、来自（本会话或子代理）、费用、占比。
- **子代理**：列出全部后代子代理的标题、启动位置（第几轮第几步）、工作中状态、时长、费用，可以打开，或在链路中定位。
- **信息**：
  - 会话信息：harness、模型、目录、状态、进程、开始与更新时间、key、源文件；
  - 恢复会话的命令、复制按钮和打开终端按钮。

## 用量视图

- **KPI 行**：总费用、输入、输出、缓存读、缓存写、步数、会话数、未定价步数（可点击，展开为未定价模型列表）。
- **时间范围**：24h、7d、30d、90d 或自定义。额外过滤条件为 harness、模型、项目。
- **分组**：可在 harness、模型、项目、目录、日期之间切换。
  - 目录分组以可下钻的树形表展示，带面包屑。
- **图表**：按日的费用趋势，按 harness 或模型堆叠，使用分类色，并附图例。
- **明细表**：可按任一列排序，可导出 CSV。
- 价格目录的同步时间与 stale 状态以徽标显示。

## 检索视图

- 输入框用于正文检索，另有过滤条件输入（会话搜索语法）。结果按会话分组，显示高亮片段。
- 视图顶部用一句白话说明用途：按会话里说过的内容（消息、思考、工具参数与输出）找会话，与侧栏按标题、目录、harness 找会话的区别；给出一两个可点击的示例。
- 全文索引不可用时说明原因和开启方式（例如守护进程以 `--no-fts` 启动）；索引在建时显示进度和预计用时，而不是只给出报错。
- 进度条只在 `indexing: true`（还有会话没建完）时出现；建完以后的实时追加不会让进度条重新出现。
- `fts.foreign_writers` 非空时显示警告：列出其他正在写索引的进程 pid 和命令，说明它们多半是升级前启动、仍在运行的旧版 uniflo，需要用户重启对应的 harness 会话或结束该进程。
- 点击片段后打开会话，滚动到对应事件并高亮。

## 管理视图

- 列表支持多选，可以按过滤条件批量选择，并显示每个会话的大小和是否可清理。
- "生成清理计划"后进入审阅页：
  - 列出可清理与不可清理的会话及原因；
  - 显示可释放空间和预计归档大小；
  - 确认后执行，并逐项展示结果。
- "归档"标签页列出归档会话及其大小，可删除归档。
- 守护进程处于 `read_only` 时，隐藏所有写操作，并给出说明。

## 洞察视图

- 一年的活跃热力图，可切换会话数、提示数、token 或费用作为指标。
- 小时 × 星期的分布图。
- 项目榜、模型榜、harness 榜，可切换指标。

## 通知

- 通知默认关闭，用户主动开启后申请浏览器的通知权限。
- 当某个会话从 work 变为 idle，且页面不在前台时，弹出通知：标题为会话标题，附带 harness 图标和耗时。
- 同一会话 30 秒内最多通知一次。
- 点击通知后打开该会话。

## 质量

- 明暗主题都可读；颜色对比满足 WCAG AA。
- 宽屏三栏与窄屏单栏布局都可用。
- 全部视图可以用键盘操作。
- 新视图沿用现有的主题变量与组件，不引入外部 CDN。
- `scripts/demo-e2e.mjs` 扩展到覆盖新视图，只用合成数据。
- 截图证据存入 `notes/evidence/`。

### Scenario: harness 图标
- GIVEN 合成数据中含全部已支持的 harness
- WHEN 打开会话视图，并请求 `GET /v1/harnesses` 与 `/v1/harnesses/claude/icon.svg`
- THEN 每个会话行显示对应 harness 的图标
- AND 除确实没有官方标识的 harness 外都显示品牌图标（含 pi、omp），字母块只作兜底
- AND 接口返回 `icon` 字段，`icon.svg` 的响应类型为 `image/svg+xml`
- AND 明暗主题下图标均可见

### Scenario: 用量视图分组、下钻与 URL 状态
- GIVEN 合成用量数据
- WHEN 在用量视图中依次执行：切换到 7d；按模型分组；切换到目录分组并下钻两级；对费用列排序；刷新页面
- THEN 页面上的 KPI 与表格数值与 `/v1/usage` 一致
- AND 下钻后的面包屑正确
- AND 刷新后视图、时间范围、分组、下钻位置和排序全部恢复
- AND 未定价步数可以展开查看模型列表，费用旁注明"API 等价成本"

### Scenario: 会话详情 tab 与恢复
- GIVEN 一个有多步 usage、两个子代理的合成 claude 会话
- WHEN 打开会话详情，依次切换到链路、用量、子代理、信息，刷新页面，再在信息 tab 点击"复制恢复命令"
- THEN 会话头下显示对话、链路、用量、子代理、信息五个 tab，只有子代理带个数；页面上没有"每步用量"按钮和右侧详情栏
- AND 会话头的费用只显示金额，悬停提示列出本会话与子代理的金额
- AND 刷新后仍停留在刷新前的 tab，URL 带 `tab` 参数
- AND 用量 tab 的合计等于 `Session.family.cost_usd`，本会话部分等于 `Session.usage.cost_usd`，最后一步上下文占用与 `/v1/sessions/{key}/usage` 一致
- AND 子代理 tab 列出两个子代理，费用与各自的 `usage.cost_usd` 一致
- AND 剪贴板内容等于 resume 接口返回的 `command`，在 macOS 上能看到"在终端打开"选项

### Scenario: 链路分层展开与记录详情
- GIVEN 同一个合成会话：两个回合，每步带思考、回复或工具调用，其中一步启动了子代理，另有一次失败的工具调用
- WHEN 打开链路 tab，展开第一轮和启动子代理的那一步，原地展开子代理，选中一个模型步骤，再按 j、k、Esc
- THEN 表头只有记录、时长、Token、费用；步骤行的 Token 合计与费用与 `/v1/sessions/{key}/trajectory` 和 `/usage` 一致，工具行显示耗时，失败的工具调用标为失败
- AND 子代理展开后显示它自己的步骤和工具，费用与子代理会话的 `usage.cost_usd` 一致
- AND 记录详情的费用一节中各类金额之和与该步 `cost_usd` 的差小于 $0.0001，各类 token 与接口一致；详情没有内层 tab，不含会话累计和吞吐
- AND j/k 在相邻行间移动选中，Esc 关闭详情
- AND 时间概览中模型、工具、子代理三条泳道各有对应的条

### Scenario: 侧栏精简
- GIVEN 合成数据含工作中与空闲会话、父会话与子代理
- WHEN 打开会话视图，打开「筛选」菜单并勾选「工作中」
- THEN 侧栏没有「会话」标题和条数、耗时；harness 选择框与「筛选」按钮在同一行
- AND 分组标题不带计数，会话行不显示模型和 pid
- AND 菜单列出 5 个筛选项；勾选「工作中」后查询为 `s:work`，按钮显示 1

### Scenario: 父会话合计子代理费用
- GIVEN 一个父会话和它的两个子代理，守护进程运行中，页面已打开会话视图
- WHEN 向其中一个子代理的会话文件追加一条 usage 记录
- THEN 侧栏父会话行显示的金额等于 `Session.family.cost_usd`，悬停提示列出本会话与子代理的金额
- AND 展开家族后，子代理行显示自身金额
- AND 追加后 3 秒内父会话行与会话头的合计更新为新值，不需要刷新

### Scenario: 检索视图跳转到事件
- GIVEN 合成数据中某个会话的中段有一条包含唯一词的事件
- WHEN 在检索视图中搜索该词，然后点击片段
- THEN 结果中显示高亮片段，点击后会话打开并滚动到该事件，事件被高亮
- AND 索引建完后向会话追加事件，检索视图不再出现建库进度条；`/v1/stats` 带非空 `fts.foreign_writers` 时检索视图显示列出 pid 的警告

### Scenario: 管理视图完成清理
- GIVEN 合成数据，守护进程使用测试注入的回收站目录
- WHEN 在管理视图中多选一个可清理会话和一个运行中的会话，生成计划，确认执行，再切换到"归档"标签页
- THEN 审阅页显示可释放空间和不可清理的原因，执行结果逐项展示
- AND 被清理的会话在列表中带归档徽标，并出现在归档标签页
- AND 以 `--read-only` 启动守护进程后，管理视图隐藏写操作并给出说明

### Scenario: 洞察视图
- GIVEN 合成数据跨越 60 天、多个项目和模型
- WHEN 打开洞察视图，切换热力图的指标和榜单的指标
- THEN 热力图格子的数值与 `/v1/usage?group_by=day` 一致；分布图与 `group_by=hour` / `weekday` 一致；榜单前 5 名与对应分组接口一致

### Scenario: 回合结束通知
- GIVEN 已开启通知并授予浏览器通知权限（在 e2e 中用替身拦截 `Notification`），页面处于后台
- WHEN 某个合成会话由 work 变为 idle，30 秒内再次发生同样的变化，另一个会话也发生同样的变化
- THEN 第一个会话只通知一次，第二个会话也通知一次，通知标题为会话标题
- AND 通知开关关闭时不发出任何通知

### Scenario: 视觉与可用性证据
- GIVEN 完成后的页面
- WHEN 在真实浏览器中用合成数据，分别在 1480px 和 390px 宽度、明暗两种主题下，对五个视图以及会话详情的五个 tab（链路含打开记录详情的状态）截图，并运行扩展后的 `scripts/demo-e2e.mjs`
- THEN 截图存入 `notes/evidence/`，无横向溢出，无元素遮挡，文字对比度符合 AA
- AND e2e 全部通过，`examples/web/index.html` 与网关内嵌副本内容一致
