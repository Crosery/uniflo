# web-console 规格

网页演示（`examples/web/index.html`，网关在 `/demo` 提供，副本位于 `crates/uniflo-gateway/src/index.html`）是 Uniflo 对外接口的参考客户端。本次重做后，它覆盖会话、用量与费用、全文检索、会话管理和活跃度洞察，并加入 harness 图标和回合结束通知。

设计上吸收 Wake 和 console 的优点：
- 品牌图标作为每行的引导；
- 过滤状态全部写进 URL；
- 未定价的项目明确显示出来；
- 失败时保留上次的数据并注明原因。

同时规避 Wake 的痛点：
- 字号过小（支持缩放、正文不小于 13px）；
- 用单色阶梯来区分系列（改用品牌色或分类色）；
- 没有实时状态（保留并强化 live 状态）。

继续保持单文件、免构建、可离线，以及既有的响应式断点与键盘操作。

## harness 图标

- 页面为每个 harness 内联一份单色 SVG，用 CSS `currentColor` 或 mask 按主题着色。来源优先 lobe-icons（MIT）；lobe-icons 没有的，用该 harness 或其厂商官方仓库、官网发布的标识（如 pi、oh-my-pi、Factory、Craft、DeepSeek），统一处理成单色，来源与许可写进 `THIRD_PARTY_NOTICES.md`。只有确实找不到任何官方标识的 harness 才显示两个字母组成的字母块，并在文档中列出。
- 网关提供 `GET /v1/harnesses/{id}/icon.svg`，`Harness` 新增可选字段 `icon`，值为该接口的路径，供外部客户端使用。
- `THIRD_PARTY_NOTICES.md` 写明 lobe-icons 的许可证和"商标归各自所有者"的声明。

## 视图与导航

- 顶部导航包含五个视图：会话、用量、检索、管理、洞察。
- 当前视图和各视图的过滤条件都写进 URL（hash 或 query），刷新或分享链接后能恢复同一状态。
- 会话列表与会话详情沿用既有能力，并新增以下内容：
  - 每行显示品牌图标；
  - 会话行显示费用和 token 摘要；
  - 归档会话带徽标；
  - 详情顶部显示会话合计：token 五项、费用（注明"API 等价成本"）和上下文窗口占用条；
  - 详情中可以展开"每步用量"表，含模型、五项 token、费用及其来源、上下文占比；
  - "恢复"按钮：复制命令，在 macOS 上还可以选择终端直接打开；
  - "清理"入口。

## 用量视图

- **KPI 行**：总费用、输入、输出、缓存读、缓存写、步数、会话数、未定价步数（可点击，展开为未定价模型列表）。
- **时间范围**：24h、7d、30d、90d 或自定义。额外过滤条件为 harness、模型、项目。
- **分组**：可在 harness、模型、项目、目录、日期之间切换。
  - 目录分组以可下钻的树形表展示，带面包屑。
- **图表**：按日的费用趋势，按 harness 或模型堆叠，使用分类色，并附图例。
- **明细表**：可按任一列排序，可导出 CSV。
- 价格目录的同步时间与 stale 状态以徽标显示。

## 检索视图

- 输入框用于正文检索，另有过滤条件输入（会话搜索语法）。结果按会话分组，显示高亮片段。
- 视图顶部用一句白话说明用途：按会话里说过的内容（消息、思考、工具参数与输出）找会话，与侧栏按标题、目录、harness 找会话的区别；给出一两个可点击的示例。
- 全文索引不可用时说明原因和开启方式（例如守护进程以 `--no-fts` 启动）；索引在建时显示进度和预计用时，而不是只给出报错。
- 点击片段后打开会话，滚动到对应事件并高亮。

## 管理视图

- 列表支持多选，可以按过滤条件批量选择，并显示每个会话的大小和是否可清理。
- "生成清理计划"后进入审阅页：
  - 列出可清理与不可清理的会话及原因；
  - 显示可释放空间和预计归档大小；
  - 确认后执行，并逐项展示结果。
- "归档"标签页列出归档会话及其大小，可删除归档。
- 守护进程处于 `read_only` 时，隐藏所有写操作，并给出说明。

## 洞察视图

- 一年的活跃热力图，可切换会话数、提示数、token 或费用作为指标。
- 小时 × 星期的分布图。
- 项目榜、模型榜、harness 榜，可切换指标。

## 通知

- 通知默认关闭，用户主动开启后申请浏览器的通知权限。
- 当某个会话从 work 变为 idle，且页面不在前台时，弹出通知：标题为会话标题，附带 harness 图标和耗时。
- 同一会话 30 秒内最多通知一次。
- 点击通知后打开该会话。

## 质量

- 明暗主题都可读；颜色对比满足 WCAG AA。
- 宽屏三栏与窄屏单栏布局都可用。
- 全部视图可以用键盘操作。
- 新视图沿用现有的主题变量与组件，不引入外部 CDN。
- `scripts/demo-e2e.mjs` 扩展到覆盖新视图，只用合成数据。
- 截图证据存入 `notes/evidence/`。

### Scenario: harness 图标
- GIVEN 合成数据中含全部已支持的 harness
- WHEN 打开会话视图，并请求 `GET /v1/harnesses` 与 `/v1/harnesses/claude/icon.svg`
- THEN 每个会话行显示对应 harness 的图标
- AND 除确实没有官方标识的 harness 外都显示品牌图标（含 pi、omp），字母块只作兜底
- AND 接口返回 `icon` 字段，`icon.svg` 的响应类型为 `image/svg+xml`
- AND 明暗主题下图标均可见

### Scenario: 用量视图分组、下钻与 URL 状态
- GIVEN 合成用量数据
- WHEN 在用量视图中依次执行：切换到 7d；按模型分组；切换到目录分组并下钻两级；对费用列排序；刷新页面
- THEN 页面上的 KPI 与表格数值与 `/v1/usage` 一致
- AND 下钻后的面包屑正确
- AND 刷新后视图、时间范围、分组、下钻位置和排序全部恢复
- AND 未定价步数可以展开查看模型列表，费用旁注明"API 等价成本"

### Scenario: 会话详情的每步用量与恢复
- GIVEN 一个有多步 usage 的合成 claude 会话
- WHEN 打开会话详情，展开"每步用量"，点击"复制恢复命令"
- THEN 每步表格与 `/v1/sessions/{key}/usage` 一致，上下文占用条显示最后一步的占比
- AND 剪贴板内容等于 resume 接口返回的 `command`
- AND 在 macOS 上能看到"在终端打开"选项

### Scenario: 检索视图跳转到事件
- GIVEN 合成数据中某个会话的中段有一条包含唯一词的事件
- WHEN 在检索视图中搜索该词，然后点击片段
- THEN 结果中显示高亮片段，点击后会话打开并滚动到该事件，事件被高亮

### Scenario: 管理视图完成清理
- GIVEN 合成数据，守护进程使用测试注入的回收站目录
- WHEN 在管理视图中多选一个可清理会话和一个运行中的会话，生成计划，确认执行，再切换到"归档"标签页
- THEN 审阅页显示可释放空间和不可清理的原因，执行结果逐项展示
- AND 被清理的会话在列表中带归档徽标，并出现在归档标签页
- AND 以 `--read-only` 启动守护进程后，管理视图隐藏写操作并给出说明

### Scenario: 洞察视图
- GIVEN 合成数据跨越 60 天、多个项目和模型
- WHEN 打开洞察视图，切换热力图的指标和榜单的指标
- THEN 热力图格子的数值与 `/v1/usage?group_by=day` 一致；分布图与 `group_by=hour` / `weekday` 一致；榜单前 5 名与对应分组接口一致

### Scenario: 回合结束通知
- GIVEN 已开启通知并授予浏览器通知权限（在 e2e 中用替身拦截 `Notification`），页面处于后台
- WHEN 某个合成会话由 work 变为 idle，30 秒内再次发生同样的变化，另一个会话也发生同样的变化
- THEN 第一个会话只通知一次，第二个会话也通知一次，通知标题为会话标题
- AND 通知开关关闭时不发出任何通知

### Scenario: 视觉与可用性证据
- GIVEN 完成后的页面
- WHEN 在真实浏览器中用合成数据，分别在 1480px 和 390px 宽度、明暗两种主题下，对五个视图截图，并运行扩展后的 `scripts/demo-e2e.mjs`
- THEN 截图存入 `notes/evidence/`，无横向溢出，无元素遮挡，文字对比度符合 AA
- AND e2e 全部通过，`examples/web/index.html` 与网关内嵌副本内容一致
