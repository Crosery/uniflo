## Uniflo 0.2.2

0.2.1 之后的修复版：未定价的模型走相似度匹配并补上免费档，价格按厂商显示名匹配，控制台「工作中」固定顺序，CLI 彩色方向键交互，终端里每次使用后提醒有新版本。

### 安装与升级

- `cargo install uniflo`
- 已装 0.2.1 或更早：`uniflo update`
- 预编译包：一行安装脚本（`install.sh` / `install.ps1`，见 README），或 `cargo binstall uniflo`

### 变化

| 模块 | 内容 |
|---|---|
| 价格匹配 | 名字比目录里的某个模型多出前缀、后缀、档位或词序不同时按词相似度匹配（如 `cursor-claude-4.5-opus-high-thinking` → `claude-opus-4-5`、`gpt-5-high-fast` → `gpt-5-fast`），版本号必须完全一致、名字里的档位词（`max`、`mini`、`flash` 等）目录里也要有，标 `approx`；`claude-4.5-opus-…` 与 `opus-5.5` 先改写成厂商拼法再找；厂商的挂牌价优先于转售方中位价 |
| 价格匹配 | 官方厂商用显示名登记的模型（如 DeepSeek 的 `deepseek-flash` 即 V4.1 Flash）按显示名命中官方价，不再落到转售方中位价；内置价格快照随版本更新，全新安装在首次同步前也能给更多模型定价 |
| 价格匹配 | 上游明确标 0/0、且没有付费同名模型的免费档（`x-preview-f-free` 之类）按零价收录；token 全为 0 的步骤不再算未定价 |
| Cursor | 旧版 IDE 会话：气泡里模型名为空串时不再盖掉会话的模型；会话没有 `modelConfig` 时取 `usageData` 里唯一的模型名 |
| 网页控制台 | 「工作中」的会话和子代理按启动顺序固定排列，不再随回答时间上下跳动 |
| 命令行 | `uniflo setup` / `uniflo clean` 在终端里用彩色横幅和方向键选择（macOS / Linux，`NO_COLOR` 与非终端回落到文字提问）；每次在终端里运行命令后，若有更新的正式版，在 stderr 打一个提醒框（后台每小时检查一次，`UNIFLO_NO_UPDATE_CHECK=1` 关闭，`daemon` / `mcp` / `--json` 不提醒） |

仍然定不了价的：目录里没有公开价格的名字（Cursor 的 `composer-*`、小米 MiMo Code 的 `mimo-auto`、各种内部代号），以及 harness 根本没记录模型的步骤（Cursor 旧版会话里很大一部分）。这两类靠更多价格来源解决不了，可以用 `<数据目录>/pricing/overrides.json` 手写价格。
