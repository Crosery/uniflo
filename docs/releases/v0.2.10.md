## Uniflo 0.2.10

`uniflo setup` 覆盖全部 33 个 harness，跨 Agent 消息升级为全 MCP 进程级 SSE 看门狗 + 10 套原生 Hook，自升级改为网络测速优先智能选源并修复失效工作目录报错，CLI 首页与接入计划视觉改版。

### 变化

| 模块 | 变化 |
|---|---|
| 全量 33 Harness 接入 | `uniflo setup` 从 16 个扩充至覆盖全部 33 个适配器（6 个官方 CLI 注册 + 15 个原子 JSON 编辑 + 12 个自动补装 Skill），新增 `workbuddy`、`commandcode`、`kilo`、`mimocode`、`zcode`（嵌套 `mcp.servers`）、`prime`、`reasonix`、`devin`、`hermes`、`minimax`、`dsh`、`crosery`、`openclaw`、`craft`、`cline`、`roo`、`kodu`，并将 `pi` 升级支持 `~/.pi/agent/mcp.json` |
| 全员进程级 SSE 看门狗 + 10 套原生 Hook | 开启可选消息功能（`uniflo mcp --message`，默认仍关闭保持 10 个只读工具）后，所有 21 个 MCP harness 启动即自动绑定随进程同生共死的轻量 SSE 看门狗线程（直连 `/v1/messages/stream?cwd=…`，推送 `notifications/message` 与 `uniflo://inbox` 资源更新、工具返回顺带投递未读消息，并新增毫秒唤醒的 `uniflo_wait_message` 第 14 工具）；同时支持 10 个原生 Hook harness（`claude`、`codex`、`gemini`、`antigravity`、`codebuddy`、`qoder`、`workbuddy`、`commandcode`、`reasonix`、`devin`）的 4 种真实配置格式与对称撤销；修复 macOS `/private/var` 路径归一化匹配 |
| 升级自动续配与新功能提示 | `uniflo update` 与 `install.sh` / `install.ps1` 统一走 `uniflo setup --after-update`：首次安装自动引导配置，后续更新静默刷新已接入条目并自动补接新检测到的 harness；`setup.json` 新增 `seen_features`，仅当版本引入未见过的新功能时才询问一次 |
| CLI 视觉与首页改版 | 新增 6 行渐变方块 `UNIFLO` Logo、`━` 分组栏与实时守护进程状态条（端口、会话数与工作中数量），裸命令 `uniflo` 与 `uniflo --help` 展示分组中英文双语首页，`uniflo setup` 计划输出改为 16 列对齐与紧凑摘要 |
| 智能选源与失效目录修复 | `uniflo update` 与 `install.sh` / `install.ps1` 改为网络并发测速优先选源（校验目标版本已同步与有效 `SHA256SUMS`，避免同步滞后或伪 200 页面误胜），无测速结果回退时区，`UNIFLO_MIRROR` 仍为硬覆盖；`cargo install` 与安装子进程显式切到系统临时工作目录，修复在已卸载/失效挂载目录运行 `uniflo update` 报 `Could not locate working directory` 的问题，并在首源下载失败时自动切次源重试 |
| Windows CI 兼容 | 修复 Windows 下 `tz.rs` 未用 `OnceLock` 警告及网关测试中 403 早断引发的 `ConnectionAborted` |

### 安装与升级

- 已安装时运行 `uniflo update`；也可用 `cargo install uniflo`、`cargo binstall uniflo` 或 GitHub Release 安装脚本。
- 预编译包覆盖 macOS arm64 / x86_64、Linux x86_64 / aarch64（musl）和 Windows x86_64，附 `SHA256SUMS`。
- 升级后首次启动会因版本缓存标签变化重建一次会话索引缓存，全文索引不重建。

没有新增生产依赖。
