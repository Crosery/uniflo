## Uniflo 0.2.4

会话页改版与资源占用版：会话详情分成对话、链路、用量、子代理、信息五个 tab，父会话合计子代理费用，侧栏和会话页去掉重复与难懂的数字；守护进程的常驻内存和 CPU 明显下降，并修复全文索引冷热双层、实时追加误报建库等问题。

### 安装与升级

- `cargo install uniflo`，或已安装时运行 `uniflo update`。
- 预编译包覆盖 macOS arm64 / x86_64、Linux x86_64 / aarch64（musl）、Windows x86_64，附 `SHA256SUMS`。
- 安装脚本与 `cargo binstall uniflo` 使用同一批发布包，见 README。
- 升级后首次启动会重建一次会话索引与用量缓存（缓存标签变化），全文索引不重建。
- 升级后重新连接旧的 MCP 进程，使其加载新版。0.2.3 之前启动的 `uniflo mcp` 会和守护进程同时写全文索引，「检索」视图会列出这些进程。

### 变化

| 模块 | 变化 |
|---|---|
| 会话页 | 会话头下方改为对话、链路、用量、子代理、信息五个 tab，替代原来的「每步用量」和右侧栏；当前 tab 写进 URL，`[` `]` 切换 |
| 链路 | 按「轮 → 步 → 记录」列出模型步骤、工具调用和子代理，带时间概览；选中一行看费用算式（逐类 token × 单价）、上下文占用和时间线 |
| 子代理费用 | 父会话显示含全部后代子代理的合计费用，悬停看拆分；子代理行仍显示自身费用，子代理用量变化时合计随推送更新 |
| 精简 | 侧栏去掉标题和分组计数，状态与时间条件收进「筛选」菜单；会话头只显示合计金额；思考不再显示字数，回合末尾写用时，只在非正常结束时写原因 |
| 全文索引 | 促温失败的会话不再同时留在冷热两层；单个会话写入失败不拖慢其余会话；实时追加不再让建库进度反复出现；进度不回退；外部删除的行会被识别并重新入索引 |
| 资源占用 | 文件监听不再跟随 SQLite 的 `-shm`；进程探测共用 `ps` 列表并缓存 `lsof`；热轮询只覆盖工作中和刚更新的会话；空闲内存交还系统；MCP 退回本地索引后 5 分钟无请求即释放 |
| 接口 | 新增 `GET /v1/sessions/{key}/trajectory`；`Session` 增加 `parent_call`、`family`，`StepUsage` 增加 `cost_parts`、`price`，`FtsStatus` 增加 `foreign_writes`、`foreign_writers`，都是可选字段，schema 版本不变 |

隔离环境实测，与 0.2.3 对比：
- 本机真实会话（5207 个）：守护进程启动 10 分钟后内存占用 360 MB → 230 MB，5 分钟平均 CPU 46.5% → 3.5%。
- 5000 个合成会话、没有写入：内存 352–372 MB → 122–134 MB，CPU 1.1–1.7% → 0.15%。
- MCP 释放本地索引后：320–355 MB → 约 10 MB。

没有新增生产依赖。
