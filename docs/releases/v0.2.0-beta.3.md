## Uniflo 0.2.0-beta.3（测试版）

这一版是 `v0.2.0-beta.2` 之后的 Windows 平台质量修复版本，重点根除守护进程周期性弹出的黑色控制台窗口与进程探测开销，并让 Web 控制台的会话恢复命令在 Windows 上可见、可一键唤起。测试版不会成为 `latest`，`cargo install uniflo` 和 `uniflo update` 默认不会装它。

### 安装

- `cargo install uniflo --version 0.2.0-beta.3`
- 已装 0.1.x / 0.2.0-beta.2：`uniflo update --pre`
- 预编译包：`UNIFLO_VERSION=0.2.0-beta.3` 加一行安装脚本（`install.sh` / `install.ps1`，见 README），或 `cargo binstall uniflo --version 0.2.0-beta.3`

### 修复与改进

| 模块 | 内容 |
|---|---|
| Windows 终端弹窗 | 新增 `uniflo-core::util::silent_cmd`，统一注入 `CREATE_NO_WINDOW`（`0x08000000`）；价格同步、更新检查、自更新解压与 `setup` 中的 `curl` / `powershell` / `tar` / `cmd` 调用全部改为静默执行，守护进程运行期不再闪现控制台窗口 |
| Windows 进程探测 | 移除每 2 秒一次的 `powershell Get-CimInstance Win32_Process`：改用 `CreateToolhelp32Snapshot`（`Process32FirstW` / `Process32NextW`）做零子进程快照预检，无候选进程时直接返回，单次枚举由数百毫秒降至亚毫秒级；探测缓存 TTL 由 2 秒放宽到 5 秒 |
| 恢复命令可见性 | Web 控制台会话详情头部新增恢复命令胶囊：悬停预览完整命令、点击一键复制；会话缺少 `cwd` 时不再清空命令，改为给出基础命令并在提示中说明建议在原工作目录执行 |
| Windows 恢复与终端 | `resume` 新增 `workbuddy` / `qwen` / `minimax` / `prime` / `factory` 恢复映射；`POST /v1/sessions/{key}/open-terminal` 在 Windows 支持拉起 Windows Terminal（`wt.exe`）/ PowerShell / CMD，Windows 环境下优先展示 PowerShell 命令 |
| 依赖 | 启用 `windows-sys` 的 `Win32_System_Diagnostics_ToolHelp` feature（进程快照 API） |

### 兼容性

- wire schema 与索引格式均未变更，`SCHEMA_VERSION` 不变。
- Uniflo 版本号参与索引缓存与全文索引的标签，升级后首次启动会自动重建两者；大库的全文索引重建耗时较长，属预期行为。
