## Uniflo 0.2.0-beta.2（测试版）

这一版是 `v0.2.0-beta.1` 之后的质量打磨版本，重点修复了各 agent harness 会话解析、运行状态推导失真以及 Web 控制台日期选择器交互缺陷。测试版不会成为 `latest`，`cargo install uniflo` 和 `uniflo update` 默认不会装它。

### 安装

- `cargo install uniflo --version 0.2.0-beta.2`
- 已装 0.1.x / 0.2.0-beta.1：`uniflo update --pre`
- 预编译包：`UNIFLO_VERSION=0.2.0-beta.2` 加一行安装脚本（`install.sh` / `install.ps1`，见 README），或 `cargo binstall uniflo --version 0.2.0-beta.2`

### 修复与改进

| 模块 | 内容 |
|---|---|
| Antigravity 解析 | `GENERIC` 通用工具执行输出正确关联前序 `ToolCall`（不再遗漏结果或被误渲染为独立助手消息）；解析并剥离元数据头 `Created At:` / `Completed At:`；剥离用户提问与预览中的 `<USER_REQUEST>` 外层标签及 `<ADDITIONAL_METADATA>` / `<USER_SETTINGS_CHANGE>` 注入块；接入 `.pbtxt`、`.db` 与 `last_conversations.json` 补齐会话标题和工作目录；接入 `agy`/`antigravity` 存活进程探测 |
| 会话状态机推导 | 修复长时间未活动或已结转的 Claude Code 会话因终端常驻卡在「工作中」的问题：适配器读取 `~/.claude/sessions/<pid>.json` 的 `status: "idle" \| "shell"` 与 `parkedJobId`；`"continued-in"` 结转与 `away_summary` / `agents_killed` 产出 `TurnEnd`；全局状态机为存活进程增加 30 分钟无新事件自动超时防呆（`idle (stale)`） |
| Web 控制台 `/demo` | 修复「用量与费用」页面自定义日期选择器弹窗残留无法关闭的问题：支持点击外部、切换时间段、切换视图或按下 `Escape` 时强制即时关闭；禁用日历 CSS 过渡延迟；支持选满日期后点击端点重新选区；`GET /demo` 增加 `Cache-Control: no-cache, must-revalidate` 响应头 |
| 跨平台与更新 | 优化 Windows 环境下的发布产物兼容性与自更新防占用替换机制；守护进程支持基于 PID 文件的优雅停机与状态查询 |

### 兼容性

- wire schema 保持兼容，`SCHEMA_VERSION` 不变。
- 索引缓存升级为 `schema1-r2`，启动时自动刷新旧缓存。
