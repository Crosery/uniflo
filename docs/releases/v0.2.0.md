## Uniflo 0.2.0

0.1.4 之后的第一个正式版：包含 `v0.2.0-beta.1` 到 `beta.3` 的全部内容，以及 beta.3 之后的全文索引分层存储、控制台改版与「接口」视图、Rust 客户端 `uniflo-client`、开发者站和价格匹配改进。

### 安装与升级

- `cargo install uniflo`
- 已装 0.1.x 或 0.2.0 测试版：`uniflo update`
- 预编译包：一行安装脚本（`install.sh` / `install.ps1`，见 README），或 `cargo binstall uniflo`

### 相比 0.1.4

| 模块 | 内容 |
|---|---|
| 用量与费用 | 每步记录输入、输出、缓存读、缓存写、推理五项 token 和 API 等价成本；`GET /v1/usage` 与 `uniflo usage` 可按 harness、模型、项目、目录、日、小时、星期、会话聚合；`GET /v1/models` 列出模型目录 |

| 全文检索 | SQLite FTS5 本地索引，`GET /v1/search`、`uniflo grep`，命中可跳到会话里的那一步 |
| 会话清理 | 计划 → 确认 → 执行：先写精简归档，再把源文件移进系统回收站，永不直接删除；`uniflo clean`、`uniflo archive` |
| 外部接入 | `uniflo mcp`、内置 Skill、`uniflo setup` 一键接入各 harness（可撤销）、`uniflo resume`、记忆与指令文件、`uniflo context` |
| 新 harness | grok、kiro、kimi、copilot、openclaw、codebuddy、craft、devin 等，共 33 个 |

| Windows | 守护进程不再弹控制台窗口；进程探测改用系统快照；恢复命令可在 Windows Terminal / PowerShell / CMD 中打开 |

### 兼容性

- wire schema 只增字段，`SCHEMA_VERSION` 不变。
- 全文索引文件改为 `fts-v2.sqlite`。升级后旁边的 `fts-v1.sqlite` 会在后台转换，转完删除，释放的空间记在 `fts.reclaimed_bytes`。之后版本号再变，只在后台就地刷新，不整份重建。
- Rust API：0.x 次版本升级，`uniflo-search` 的 `FtsOptions` 新增 `verify_threads` 字段。用结构体字面量构造的调用方要补上这个字段，或改用 `..Default::default()`。
