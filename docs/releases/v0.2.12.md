## Uniflo 0.2.12

重点强化网关高并发稳定性与后台资源占用，修复并发缓存、探针风暴与 Antigravity 实时探测 CPU 飙升问题；同时全面升级 `/demo` 控制台的对话区视觉与 41 家 AI 模型品牌图标自动识别。

### 变化

| 模块 | 变化 |
|---|---|
| 网关高并发修复与缓存优化 | 修复 `GET /v1/messages/peers` 子进程惊群（`probe_herdr` / `probe_tmux` 双检互斥锁 + `parent_pid_map` 2s 缓存 + 网关 `Singleflight` + `cpu_permits`，8 并发压测由 1.83s / 6 rps 降至热态 1.0ms / 13,903 rps、冷态 115.7ms）；修复 `ResponseCache` 旧代际迟到写入反清更新代际条目、以及 `Singleflight::run` 领队被取消后所有等待者同时击穿的两个并发缺陷，并消除锁毒化 panic 传播；新增独立 `io_permits` 信号量限制单会话磁盘并发读、`limit > 500` 大列表转入阻塞池；为 `/v1/sessions/{key}/trajectory` 补齐按会话零拷贝缓存，无筛选 `/v1/models` 切换为 `membership_gen` 不再被活跃流高频击穿；`MessageBus` 新增 `by_sender` 索引并将同步落盘 `send`/`ack` 移出 Tokio 异步线程；SSE/WS 截断路径增加 `needs_truncate()` 零克隆快路径 |
| 引擎与 Antigravity 后台 CPU 降载 | `Engine::health_snapshot()` 改读无锁原子计数、`session_arc()` 快照过期时 O(1) 直查，不再因单次查询或心跳触发数千会话全量重建与排序；`cached_roots()` 补双检锁。`Antigravity` 实时探针增加 2s `live_cache` 节流并合并多未匹配进程为单次 `brain/` 目录扫描，`cwd_of()` 优先 O(1) 查内存 `summary_index` 再回退 SQLite，`conv_dbs` 设 256 上限防内存无限增长，`sidecar_sig()` 合并重复索引检查；6,259 真实会话稳态空载 CPU 由 25%–65% 降至 2.2%–7.9%，RSS 降至 ~68–76 MB |
| `/demo` 对话区与 41 家模型品牌图标 | 参考 Herdr Pocket 与 t3code 的无边框 WorkLog 布局重做 `/demo` 对话流、工具执行折叠组与底部悬浮输入框；集成 41 家主流 AI 模型与厂商官方品牌图标（`@lobehub/icons`，MIT），在会话列表、顶栏、信息页与底部输入框按模型名自动匹配厂商图标（Claude、OpenAI/GPT、Gemini、DeepSeek、Qwen、GLM、MiniMax、Kimi、Grok、Mistral、Llama 等） |
| 跨平台构建修复 | 拆分 `deliver.rs::parent_pid_map` 条件编译，消除 Windows（`x86_64-pc-windows-msvc`）下的 `unused_mut` 编译告警 |

### 安装与升级

- 已安装时运行 `uniflo update`；也可用 `cargo install uniflo`、`cargo binstall uniflo` 或 GitHub Release 安装脚本。
- 预编译包覆盖 macOS arm64 / x86_64、Linux x86_64 / aarch64（musl）和 Windows x86_64，附 `SHA256SUMS`。

没有新增 Rust 生产依赖；网页演示新增 `@lobehub/icons`（MIT）内联 SVG，已登记至 `THIRD_PARTY_NOTICES.md`。
