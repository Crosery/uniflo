## Uniflo 0.2.0-beta.1（测试版）

这一版的重点是让外部服务和 agent 更方便地接入 Uniflo，同时补上用量与费用统计、正文检索和会话清理。测试版不会成为 `latest`，`cargo install uniflo` 和 `uniflo update` 默认不会装它。

### 安装

- `cargo install uniflo --version 0.2.0-beta.1`
- 已装 0.1.x：`uniflo update --pre`
- 预编译包：`UNIFLO_VERSION=0.2.0-beta.1` 加一行安装脚本（`install.sh` / `install.ps1`，见 README），或 `cargo binstall uniflo --version 0.2.0-beta.1`

### 新功能

| 模块 | 内容 |
|---|---|
| 用量与费用 | 每步记录输入、输出、缓存读、缓存写、推理五项 token 和费用（API 等价成本）；`GET /v1/usage` 与 `uniflo usage` 按 harness、模型、项目、目录、日、小时、星期、会话聚合，支持时间窗、时区、目录下钻；单会话每步明细含上下文占用；`GET /v1/models` 模型目录 |
| 价格同步 | 内置价格快照（models.dev，缺项用 LiteLLM 补），守护进程启动约 1 分钟后同步、之后每 6 小时一次，超过 24 小时未成功标 `stale`；`overrides.json` 永远优先；`uniflo pricing`、`uniflo pricing sync`、`--no-price-sync` |
| 全文检索 | SQLite FTS5 本地索引消息、思考、工具参数与输出，中文与代码按子串匹配；`GET /v1/search`、`uniflo grep`，命中可跳到会话中的那一步；`--no-fts` 关闭 |
| 新 harness | grok、kiro、kimi、copilot、openclaw、codebuddy、craft、devin；cursor 补读 IDE 元数据（标题、目录、模型、时间、子代理父会话） |
| 会话清理 | 计划 → 确认 → 执行：先写 zstd 精简归档（保留正文和全部用量，丢掉图片等二进制），再把源文件移进系统回收站，永不直接删除；归档会话仍可列出、查看、检索、计入用量（`is:archived`）；`uniflo clean`、`uniflo archive`；支持 20 个 harness |
| 外部接入 | `uniflo mcp`（10 个只读 MCP 工具）、内置 Skill（`uniflo skill print`）、`uniflo setup` 一键接入各 harness（默认 MCP，可撤销）、`uniflo resume` 与恢复命令接口、agent 记忆与指令文件目录、`uniflo context` 接力上下文 |
| 打开终端 | 网页与 `POST /v1/sessions/{key}/open-terminal` 在 Terminal、iTerm、Ghostty 中直接恢复会话，不需要 macOS「自动化」权限；失败时给出原因和可复制的命令 |
| 分发与更新 | GitHub Releases 提供 5 个平台预编译包与 `SHA256SUMS`、安装脚本、cargo-binstall 元数据；`uniflo update` 按安装方式（cargo / 预编译包）升级，校验失败不改动原程序 |
| 网页演示 `/demo` | 会话、用量、检索、管理、洞察五个视图；harness 品牌图标；用量 KPI、趋势图、目录树、CSV 导出；检索说明与空状态；清理计划审阅与归档管理；活跃热力图与排行；回合结束通知；筛选与日期改用组件库（Tom Select、Air Datepicker） |

### 安全

- 所有写接口统一经过写守卫：只认本机 Host、Origin 白名单、必须带 `X-Uniflo-Write: 1`、token；`--read-only` 时全部拒绝。
- 除会话清理和 `uniflo setup` 这两处需用户确认、可撤销的例外外，harness 会话数据仍只读。

### 兼容性

- wire schema 只增字段，`SCHEMA_VERSION` 不变。
- Rust API：`Usage` 不再实现 `Copy` / `Eq`，因此升次版本号。
- 全文索引首次构建较慢（本机约 5.6 GB、约 14 分钟），升级版本会整份重建；守护进程常驻内存会比 0.1.x 高。
