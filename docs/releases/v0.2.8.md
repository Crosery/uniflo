## Uniflo 0.2.8

修复网页控制台的历史分页与「到最顶」。

### 变化

- 工具调用和结果分处相邻两页时，修复加载更早历史过程中因插入锚点失效而误报加载失败的问题。
- 「到最顶」固定在对话滚动区顶部，点击后以一次请求打开会话最早一页，不再逐页向前加载；「跳到最新」可返回最新事件。
- 历史请求遇到短暂网络故障时自动重试；持续失败时显示实际错误原因。
- 事件接口新增 `oldest=true`，可直接读取会话最早一页。

### 安装与升级

已安装时运行 `uniflo update`；也可用 `cargo install uniflo` 或 GitHub Release 安装脚本。预编译包覆盖 macOS arm64 / x86_64、Linux x86_64 / aarch64（musl）和 Windows x86_64，附 `SHA256SUMS`。
