## Uniflo 0.2.9

全链路高并发低延迟优化，新增默认关闭的可选跨 Agent 消息总线（ADR-0012），并完善 Antigravity（`agy`）的用量、定价与接入支持。

### 变化

| 模块 | 变化 |
|---|---|
| 网关与引擎并发 | 会话列表改用 `Arc<Session>` 按代数懒发布的不可变预排快照与无锁健康状态；后台存活探测、磁盘重扫与缓存落盘移出读写锁；网关新增按数据代数隔离的响应缓存、取消安全 Singleflight 同键合并与重计算并发限流 |
| 用量、全文与适配器热点 | 用量时区解析改为每次查询解析一次并走常量偏移快路径，账本维护预聚合区间摘要，价格刷新增加原子时间窗快路径；全文检索消除全表计数扫描与排序克隆并限制冷层并行校验并发槽；Antigravity 共享摘要库侧车改为按会话确定性哈希签名，避免单会话写入触发全量重读 |
| 跨 Agent 消息总线（可选） | 新增本地消息总线（`GET/POST /v1/messages`、`POST /v1/messages/ack`、`GET /v1/messages/stream` SSE 实时推流）与 `uniflo message send\|inbox\|ack\|watch\|hook`，支持精确 key、唯一前缀与 `cwd:<目录>` 寻址；首次发信才在数据目录懒创建 `messages/log.jsonl`，对所有 harness 数据保持只读，写接口受写守卫与 `--read-only` 保护 |
| 默认关闭的按需接入 | `uniflo setup` 与 `uniflo mcp` 默认保持纯只读 10 工具、不写入任何消息 hook；仅显式传入 `--message`（或交互选择开启）时启用 `uniflo mcp --message`（额外暴露 `uniflo_send_message`、`uniflo_inbox`、`uniflo_ack_messages`）及静默拉取 hook，支持 `--reload` 切换与 `--uninstall` 对称清理；网页控制台「接口」视图同步收录消息接口 |
| Antigravity 完整支持 | 解析每步模型与用量（`transcript.jsonl` + 只读缓存 `conversations/<id>.db`），补齐推理强度后缀的定价匹配、swarm 子会话挂接、`.db-shm` 与 `presence/<id>.lock` 存活映射；`uniflo setup` 支持 Antigravity（`agy` 别名）接入，`uniflo memory` 读取 `~/.gemini/config/GEMINI.md` 与项目 `.agents/rules/*.md` |

隔离环境实测（本机 6,190–6,204 真实会话）：
- 60 并发混合负载：总耗时 `1,762 ms` → `12.05 ms`（`/v1/health` p50 `1.12 ms`、`/v1/sessions` p50 `2.46 ms`、`/v1/usage` p50 `2.78 ms`）。
- 极限吞吐：`/v1/health` 峰值 `130,041 QPS`（200 并发 p50 `1.27 ms`），`/v1/sessions` 峰值 `57,039 QPS`（64 并发 p50 `0.84 ms`）；消息写入 `POST /v1/messages`（真实落盘）峰值 `19,440 QPS`，100 并发 SSE 订阅扇出 100% 在 `4 ms` 内送达。

### 安装与升级

- 已安装时运行 `uniflo update`；也可用 `cargo install uniflo`、`cargo binstall uniflo` 或 GitHub Release 安装脚本。
- 预编译包覆盖 macOS arm64 / x86_64、Linux x86_64 / aarch64（musl）和 Windows x86_64，附 `SHA256SUMS`。
- 升级后首次启动会因缓存标签与账本版本变化重建一次会话索引与用量缓存，全文索引不重建。

没有新增生产依赖。
