## Uniflo 0.2.11

跨 Agent 通讯升级为**零 Hook 三层实时唤醒**，彻底解决空闲会话叫不醒与同目录看门狗截胡问题；`/demo` 控制台新增底部悬浮 Chat UI 对话框，支持在网页里直接向任意本地会话发消息并实时查看回复。

### 变化

| 模块 | 变化 |
|---|---|
| 零 Hook 三层主动投递与回复捕获 | 新增 `uniflo-core::deliver` 主动投递引擎，无需任何 Harness Hook 即可自动按三层送达：1）Herdr 活终端精准直推（16 并发探测 + 8s 缓存 + `fg_pid`/进程树匹配 + 权限确认弹窗保护 + `herdr-core send --`）；2）tmux 活窗格直推（空格分隔兼容 `launchd` `C` locale + `capture-pane` 权限保护 + `send-keys -l --`）；3）官方无头原上下文续跑（覆盖 `agy`、`claude`、`codex`、`opencode`、`omp`、`pi`、`gemini`、`cursor-agent`、`codebuddy`、`qodercli`、`workbuddy`、`droid` 12 家 CLI，失败如实返回 `resume_failed` 与退出码）。带 `wait_secs` 发送时提前同时订阅消息总线与 FSEvents 事件流，对端正常回复即可自动抓回正文；服务端内置 `MAX_AUTO_WAKE_HOPS = 2` 防循环保护；`enriched_path()` 与 `scripts/install-service.sh` 补全 `launchd` 缺失的 `~/.local/bin`、`~/.bun/bin`、`/opt/homebrew/bin` |
| 同目录防截胡与一步互聊 | `uniflo mcp --message` 按环境变量与守护进程进程树自动识别自身 `self_key`，看门狗精确过滤自发与发往他人的消息，绝不在共享目录（如 `~`）截胡对端的 `delivered_at`；`cwd:` 寻址自动排除发送方自身；新增 `GET /v1/messages/peers` 与第 15 个工具 `uniflo_peers`（默认纯只读 `uniflo mcp` 仍保持 10 工具），按「同目录 → 工作中或近 15 分钟活跃 → 旧存活空闲 → 历史空闲」排序并支持 `cwd` / `prefer_cwd`；`uniflo_send_message` 与 `uniflo message send` 支持默认自动唤醒与 `--wait` / `wait_secs` 一通调用直接拿回复 |
| `/demo` 底部 Chat UI 对话框 | 借鉴 Herdr Pocket 卡片质感，在对话底部新增磨砂悬浮输入框（自动增高、Enter 发送 / Shift+Enter 换行、实时通道徽章、`自动唤醒 / 仅收件箱` 切换、圆形发送按钮），对话流内联渲染实时双向气泡（支持 `已回复` / `原上下文唤醒` / `Herdr 直推` / `唤醒失败` 状态标签）并订阅 `/v1/messages/stream` 实时刷新；`--read-only` 与归档会话自动隐藏，适配 390px 移动端窄屏 |
| 网关与 Schema 增量扩展 | Wire schema v1 只增不改：`SendMessageRequest` 新增可选 `deliver` / `wait_secs` / `hop`，`SendMessageResponse` 新增可选 `delivery_channel` / `delivery_detail` / `reply`，新增 `PeerInfo` / `PeersResponse` 及 `GET /v1/messages?peer=<key>` 双向过滤 |

### 安装与升级

- 已安装时运行 `uniflo update`；也可用 `cargo install uniflo`、`cargo binstall uniflo` 或 GitHub Release 安装脚本。
- 预编译包覆盖 macOS arm64 / x86_64、Linux x86_64 / aarch64（musl）和 Windows x86_64，附 `SHA256SUMS`。
- 若此前已通过 `scripts/install-service.sh` 安装 macOS `launchd` 服务，升级后可按需重跑该脚本或确认 plist `PATH` 包含用户 CLI 目录（引擎内置的 `enriched_path()` 亦会自动兜底查找）。

没有新增生产依赖。
