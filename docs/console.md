# 网页控制台

> 守护进程在 `/demo` 提供的单文件网页客户端：六个视图、三栏会话页、命令面板、主题与隐私模式；源码 `examples/web/index.html`，无外部运行时依赖、免构建，也可以复制出去改造。

状态：`current` · 更新：2026-10-26

打开：`uniflo daemon` 之后访问 `http://127.0.0.1:7311/demo`。

![会话视图](assets/demo.png)

## 视图

左侧导航栏六个视图（数字键 `1`–`6` 切换，手机宽度变为底部标签栏），视图、过滤、下钻和排序都写进 URL，刷新或分享链接原样恢复：

- **会话**：实时会话流，会话头下方是对话、链路、用量、子代理、信息五个 tab，见下。「恢复」复制恢复命令，macOS 上还可直接在 Terminal / iTerm2 / Ghostty 中打开（用 `open` 启动，不需要「自动化」权限；失败时给出原因和可复制的恢复命令）。
- **用量**：24 小时 / 7 / 30 / 90 天或自定义区间，按 harness、模型、项目过滤；KPI（总费用带每日走势、日均和与上一个同长区间的对比）、按 harness 或模型堆叠的每日费用图、可排序明细表（harness / 模型 / 项目 / 目录 / 日期分组，目录可逐级下钻，带面包屑），导出 CSV。费用一律标注「API 等价成本」，未定价的步骤单独计数并可展开到模型列表。
- **检索**：全文检索，结果按会话分组、命中词高亮；点击片段打开会话并滚动到该事件高亮。建库进度条只在还有会话没建完时出现；`/v1/stats` 报告有别的进程在写索引（`fts.foreign_writers`，多半是升级前启动的旧版 uniflo）时，列出它们的 pid 和命令并说明怎么处理。
- **管理**：勾选会话（整行可点，选中后底部出现批量操作条）→ 生成清理计划（可释放空间、预计归档大小、不可清理的原因）→ 确认执行，逐项显示结果；「归档」页查看与删除归档。守护进程以 `--read-only` 启动时隐藏所有写操作并说明原因。
- **洞察**：最近一年的每日热力图、星期 × 小时分布（可选 30 / 90 天或一年）、项目 / 模型 / harness 前 5 排行，可切换会话 / 提示 / token / 费用指标；按 harness / 模型 / 项目筛选，点排行项也可筛选；点热力图或星期 × 小时的格子弹出当天 / 该时段的明细卡（当天按 harness 等维度的占比和前 3 个会话），方向键切换格子。
- **接口**：守护进程的全部 REST 与实时流接口（`docs/api.md` 里的每一行），选一个接口、填参数、发送，直接看本机的真实返回：状态、耗时、大小、响应头，JSON 按可折叠的结构树展示（时间戳、字节数旁附可读值，大数组分页展开），也可看原始 JSON；SSE / NDJSON / WebSocket 连上后逐条列出 Envelope。每个请求附 curl、JavaScript 与 Rust SDK（`uniflo-client`）写法。会改动数据或打开窗口的写接口只给写法、不发送；生成清理计划只算计划，可以发送。

## 会话视图

- 左侧只留核心信息：
  - 最上面是 fd/fzf 式搜索；
  - 下面一行是可搜索的 harness 单选下拉和「筛选」按钮。「筛选」菜单有工作中、进程在运行、隐藏子代理、最近 24 小时、已归档，每项附一句说明；勾选即写入查询，按钮上显示已启用的个数。
  - 会话列表按「工作中 / 今天 / 昨天 / 最近 7 天 / 更早」分组，分组不带计数。每行是 harness 图标、标题、目录、时间和费用，工作中的会话带脉冲点；不显示模型和进程号（在「信息」tab 里），低于 $0.01 或未定价的费用不显示。
  - 有子代理的父会话显示含全部后代子代理的合计费用（悬停看「本会话 + N 个子代理」的拆分），子代理行显示自身费用；子代理用量变化时合计随推送更新。选择新的 harness 会替换原来的正向 `h:` / `harness:` 条件，保留其他查询条件；选「全部 harness」清除该条件。
- 「工作中」按本轮进入工作状态的先后排列，不按会话创建时间或最后回答时间。会话和子代理持续工作期间位置固定，空闲后重新工作排到当前队列末尾；父家族只要仍有成员工作就保留队列位置。空闲分组仍按最近活动排序。
- 子代理挂在父会话下面：缩进并用连接线连到父会话图标，分支第一行是「N 个子代理 · M 工作中」。默认只列正在工作的子代理：有子代理在工作时这一家自动展开，没有时收起成这一行。末尾「显示 N 个空闲子代理」按工作中优先、再按最近活动加载其余的，每次 10 个（「再显示 10 个」），「只看工作中」或「收起」回到默认；第一行也可以手动收起或展开。当前打开的子代理始终可见，停止工作也不会从列表里消失。一家子按最活跃的成员归组和排序：子代理在工作时，父会话也排进「工作中」，分组计数按顶层条目算。父会话不在列表里（被过滤或超出条数）的子代理单独列出，标「↳ 子代理」。
- 子代理的会话头显示「子代理 · 父会话 <标题>」，点击打开父会话。会话头的元信息只显示合计金额，拆分在悬停提示里；会话内不足 1 美分的金额显示 4 位小数。
- 会话头下方是一排视图 tab（参照 DeepSeek Harness 的「对话 / 轨迹」）。当前 tab 写进 URL 参数 `tab`，切换会话时保持；`[` `]` 切换上一个 / 下一个 tab，tab 栏获得焦点后也可用方向键：
  - **对话**：归一后的会话流——用户气泡（时间悬停才显示）、Markdown 回复（代码块可复制）、折叠的思考、一行一个的工具调用（参数 + 输出 + 耗时 + 状态）。回合末尾写用时和结束时间，非正常结束时写原因（已中断、出错等）。
  - **链路**：数据来自 `GET /v1/sessions/{key}/trajectory`。
    - 工具栏：展开 / 收起全部轮次，「实际时长 / 等宽」切换时间概览刻度，搜索链路（按名称、参数摘要、回复预览过滤，只留命中的记录及其所在的轮和步）。
    - 时间概览：模型、工具、子代理三条泳道，虚线是轮次分界，选中记录所在的轮次高亮；点击条形定位到对应记录。
    - 表格按「轮 → 步 → 记录」分层，列为时长、Token、费用（Token 是四类之和，分项在悬停提示里）。轮次行带用户输入预览，费用含本轮启动的子代理；步骤行的模型与会话不同时才标出；记录行是思考、回复（预览）、工具调用（参数摘要、耗时、成功 / 失败 / 运行中）和子代理（可原地展开它自己的步骤和工具）。窄窗口时先隐藏 Token，再隐藏时长，费用始终保留。
    - 选中一行，右侧打开记录详情，`j` / `k` 上下切换，`Esc` 关闭。详情一屏滚动、不分 tab：模型步骤依次是费用（逐类 token × 单价 = 金额，合计等于该步费用）、上下文占用、时间线（请求开始、模型生成、各工具、下一步开始；按相邻事件推算）和「在对话中定位」；工具调用是参数和结果；子代理是费用与各类 token、打开会话。
  - **用量**：合计（本会话 + 全部子代理）及拆分、最后一步上下文占用、按轮分组的每步费用柱图（子代理费用叠在启动它的那一步，点击柱子跳到链路中的该步）；用到不止一个模型时再列按模型的费用和占比。
  - **子代理**（带个数，是唯一带数字的 tab，没有子代理时不显示）：全部后代子代理的标题、启动位置（第几轮第几步）、工作中状态、时长、费用，可以打开，或在链路中定位。
  - **信息**：harness、模型、目录、状态、进程、开始与更新时间、key、源文件，以及恢复命令（复制、在终端中打开）。

## 导航栏、命令面板与通知

- 导航栏底部四个按钮都带文字：「命令」打开命令面板，「通知」开关回合结束通知（关闭时图标带斜线），「主题」在跟随系统 / 浅色 / 深色之间切换，「实时」是连接状态；窗口高度不足 760 px 时前三个只显示图标。
- 导航栏底部的连接状态打开「连接与诊断」抽屉：切换 SSE / WebSocket / NDJSON，14 个接口的实时自检与延迟、索引健康度、实时 Envelope 流。
- `⌘K` / `Ctrl+K` 命令面板（视图、操作、会话）；主题可跟随系统或固定浅色、深色；`/` 搜索，`j` `k` 切换会话。
- 回合结束通知（铃铛按钮，默认关闭）：页面在后台时，会话从工作转为空闲会弹系统通知，标题是会话标题，同一会话 30 秒内最多一次，点击通知打开该会话。
- harness 显示单色品牌图标（[lobe-icons](https://github.com/lobehub/lobe-icons)，MIT，加各家官方标识，来源见 `THIRD_PARTY_NOTICES.md`）。没有图标的显示字母块：`crosery`（自家 harness，没有矢量标识）、`prime`（Prime Intellect 官方站点无法取得矢量标识）、`kodu`（仓库为 AGPL-3.0，已停止维护）。

## 布局与 URL 参数

- 响应式布局：宽屏两栏（会话列表 + 会话内容），≤1180px 列表收窄、链路的记录详情变窄，≤760px 改为会话列表 / 会话内容单栏切换、导航移到底部、链路的记录详情从底部弹出；「会话列表」按钮或 `Esc` 返回列表，`/` 打开搜索。通知与工具标题按内容撑高，不遮挡相邻行。
- URL 参数：`?api=http://127.0.0.1:7311`（从其他本地端口打开时）、`?token=`、`?transport=ws`、`?select=<key>`、`?view=<视图>`、`?redact`（模糊所有正文、标题与路径，便于录屏）。

## 依赖与验收

- harness 下拉等选择控件使用 [Tom Select](https://tom-select.js.org/) 2.6.2：脚本、样式及 Apache-2.0 许可证已内嵌，不请求 CDN，也不需要 npm 安装或前端构建。触发器、弹层、选中项和焦点沿用页面主题 token，弹层支持内部滚动及短视口向上展开。
- `scripts/demo-e2e.mjs` 用无头 Chrome 对它做端到端验收（合成数据，不碰真实会话）：三种传输、全部接口、实时追加延迟、work/idle 切换、跨域接入与 token；全部 harness 的图标、用量与 `/v1/usage` 逐项一致、检索跳转、洞察与分组接口一致、通知节流、清理（临时 `UNIFLO_TRASH_DIR`）与只读模式、侧栏精简与「筛选」菜单、会话 tab（链路与 `/trajectory`、`/usage` 一致，子代理原地展开，记录详情的费用拆分，`j` / `k` / `Esc`，父会话合计实时更新）、命令面板、诊断抽屉、主题切换、洞察筛选与明细卡、「接口」视图；再按 6 个视图和 5 个会话 tab（链路含打开记录详情）× 1480 / 390 px × 明暗主题截图，检查横向溢出、元素重叠和 WCAG AA 对比度。打开终端被页面内拦截，不会弹出真实窗口。
- `/demo` 从 `crates/uniflo-gateway/src/index.html` 编译进守护进程；修改演示页时需同步该副本，再重新构建并重启守护进程。页面每 5 秒读一次 `/v1/health`，重连时也看 `hello` 的 `server`：守护进程换了版本（如 `uniflo update` 之后）就自动刷新一次载入新页面，URL 里的视图、查询和选中会话保留；同一版本只刷新一次，从别的地址打开（`?api=`）时不刷新。
- 本页截图（`assets/`）来自 `scripts/demo-e2e.mjs` 的合成数据截图，不含真实会话。
