# ADR-0004 · 网关默认只监听本机

> 会话里有代码、路径、甚至密钥；网关默认只服务回环地址，并校验 Host 与 Origin。

状态：`accepted` · 更新：2026-10-02

## 背景

浏览器里的任意网页都能向 `127.0.0.1` 发请求；DNS rebinding 可以绕过同源策略读取本地服务。会话内容属于高敏感数据。

## 决策

- 默认绑定 `127.0.0.1:7311`。
- Host 头必须是回环名（或 `--allow-host` 显式列出），否则 403。
- 带 Origin 的请求只放行回环来源和 `--cors-origin` 显式列出的来源。
- 可选 token（`--token` / `UNIFLO_TOKEN`），常量时间比较；`--allow-host` 必须同时设置 token，否则拒绝启动。
- 网关只读，没有写接口。

实施状态：已落地（`crates/uniflo-gateway/src/guard.rs`，测试 `tests/gateway.rs::guard_blocks_foreign_hosts_origins_and_missing_tokens`）。

## 否决项

- 默认 `0.0.0.0` + 无鉴权：局域网任何人可读全部会话。
- 只靠 CORS：CORS 不阻止请求发出，也挡不住 DNS rebinding。

## 后果

- 远程访问需要用户显式配置 Host 白名单和 token（或自行 SSH 转发）。

## 复议触发

需要多用户 / 远程托管场景时，改为正式鉴权（OAuth / mTLS）。
