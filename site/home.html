能力

      
做面板、做 agent、做分析，底层这一层不用再写

    

    

      ⇄实时网关
REST、SSE、NDJSON、WebSocket 四种接法，同一份数据；默认只听回环，可选 token。

      ⌕搜索与全文检索
fd 式过滤加 fzf 式模糊：s:work h:claude since:2h；中文词和代码子串直达事件。

      $用量与费用
统一 token 口径，按 harness、模型、项目、日期聚合，未定价的单独计数，不按 0 算。

      ✦agent 直接可用
uniflo mcp 与随二进制分发的 Skill，uniflo setup 一条命令接入本机 harness。

      ⧉Rust crate
wire 类型、嵌入式引擎、网关客户端都在 crates.io，可以不跑守护进程直接嵌入。

      ⛨只读与隐私
默认不写任何 harness 数据；清理与 setup 两处例外都要确认、可撤销。

    

  


  

    

      
接入

      
四种接法，挑最顺手的

    

    

      

        
        
        
        
      

      
sh
# 正在工作的 Claude 会话
curl -s '127.0.0.1:7311/v1/sessions?q=s:work%20h:claude' | jq '.[].title'
# 全文检索，命中直达事件
curl -s '127.0.0.1:7311/v1/search?q=缓存击穿&limit=5'

      
js
const es = new EventSource("http://127.0.0.1:7311/v1/stream");
es.addEventListener("event", (m) => {
  const { event } = JSON.parse(m.data);
  if (event.kind === "tool_call") console.log(event.session, event.name);
});

      
rust
// cargo add uniflo-client
let client = uniflo_client::Client::local()?;
for s in client.sessions("s:work", 20)? {
    println!("{} · {}", s.key, s.title.unwrap_or_default());
}
